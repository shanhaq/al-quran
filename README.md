# Al-Quran — Read, Understand & Listen

Android app: Quran ko asli kitab ki tarah padho, har ayah ke neeche tarjuma
dekho, aur Arabic + tarjuma audio suno.

## Look preview

Live: https://shanhaq.github.io/al-quran/

3 design directions (Mushaf Classic / Midnight Glass / Editorial Signal) —
look pick hone ke baad app build hoga.

## Data sources (verified)

- Quran text (Uthmani) + translations: quran.com API v4 / alquran.cloud API
- Per-ayah Arabic audio: verses.quran.com (quran.com), everyayah.com, cdn.islamic.network
- Mushaf page layout (604 pages / 30 juz): alquran.cloud `/v1/page/{n}`
